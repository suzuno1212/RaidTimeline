困ったとき

よくあることと、見るところ。

アドオン

メニューに RaidTimeline が出ない

  • LuaMods\RaidTimeline\module.def と RaidTimeline.lua が同じフォルダにあるか確かめてください（zip を展開して RaidTimeline\RaidTimeline\ と二重になっていることがあります）。
  • Lua を読み込み直してください。コンソールに [RaidTimeline] で始まる行が出ていれば読み込めています。

ドライランの画面に何も出ない

  • 「ドライラン」が ON か。
  • timelines\ に、今のマップの <mapid>_*.lua があるか。画面の「タイムライン」に「なし」と出ていれば、ありません。
  • 戦闘開始のとき、タイムラインの敵がターゲットできる状態か（道中の雑魚では動きません）。

時刻がずれる・照合されない

  • 1 プルだけで作ったタイムラインは、ばらつきが分かりません。プルを増やして作り直すと安定します。
  • ギミックや火力で長さが変わる所は、変換ツールでフェーズを区切ってください（フェーズを区切る）。
  • logs\<mapid>\ の判定のログに、照合・同期・未照合が残ります。

アクションを使わない

  • 「実行する（oGCD）」が ON か、一時停止中でないか、そのエントリの「実行」が外れていないか。
  • 判定の結果を見てください。「同等効果あり」「直前に使用済み」「リキャスト中」なら、そのとおりの理由です。
  • ウェポンスキル・魔法（GCD）は使いません（アビリティだけ）。

音が鳴らない

  • 「音を鳴らす」と「ドライラン」の両方が ON か。
  • wav が RaidTimeline\wav\ にあり、ファイル名・フォルダのパスが英数字だけか。
  • ドライランの画面の「音」の「テスト再生」で鳴るか。

プランを壊してしまった

プラン編集の「元に戻す」、または plans\<mapid>\backup\ から前の版をコピーして戻せます（10 世代）。

変換ツール

起動しない・画面が白い

  • Microsoft Edge WebView2 ランタイムを入れてください（Microsoft の公式サイトから「Evergreen」版）。
  • zip のまま起動していないか（展開してから起動します）。

アドオンのフォルダが見つからない

設定の「LuaMods\RaidTimeline」の「選ぶ」で指定して「保存」してください。次からはその場所を使います。

リプレイを開くとエラー・敵が出ない

  • ゲームの大きな更新のあとは、リプレイの中身の形が変わって読めないことがあります。その場合は新しい版のツールを待ってください。記録ログだけでも作れます。
  • リプレイに戦闘が入っていないと（入ってすぐ抜けた など）、何も出ません。

「別のコンテンツのファイルが混ざっています」

リプレイ＋記録ログで、別のマップの記録ログを選んでいます。そのファイルは使われません。気になるなら選び直してください。

ファイルの場所のまとめ

LuaMods\RaidTimeline\
├─ RaidTimeline.lua, module.def   … アドオン本体（更新で上書き）
├─ settings.lua                   … 設定（自動で作られる）
├─ timelines\<mapid>_*.lua        … タイムライン
├─ plans\<mapid>\<ジョブ>_<ポジション>.lua
│  └─ backup\                     … プランの前の版
├─ logs\<mapid>\                  … 記録・判定のログ（1 プル 1 ファイル）
├─ names\actions.lua              … 自分で直した技名（変換ツール）
└─ wav\                           … 音

不具合を見つけたら

GitHub の Issues へ。何をしたか・どうなったか・アドオンとツールの版を書いてください。ログやリプレイを貼るときは、キャラクター名など個人が分かる情報が入っていないか確かめてください。
